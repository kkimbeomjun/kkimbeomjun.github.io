도커 명령어로 컨테이너 하나 띄우는 건 간단한데, 실제 프로젝트에서는 컨테이너를 여러 개 같이 쓰는 경우가 많아요. 예를 들어 웹 서버랑 데이터베이스를 같이 올려야 한다거나요. 그럴 때 매번 `docker run` 명령어를 여러 번 치는 건 번거로워요.

docker-compose는 이걸 파일 하나로 정리해서 한 번에 실행할 수 있게 해줘요.

## docker-compose.yml 기본 구조

프로젝트 폴더에 `docker-compose.yml` 파일을 만들고 아래처럼 작성해요.

```yaml
services:
  web:
    image: nginx
    ports:
      - "8080:80"

  db:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: 1234
      MYSQL_DATABASE: mydb
```

`services` 아래에 컨테이너를 원하는 만큼 정의하면 돼요. 여기선 nginx 웹 서버랑 MySQL 데이터베이스 두 개를 같이 쓰는 예시예요.

자주 쓰는 항목이에요.

| 항목 | 설명 |
|------|------|
| `image` | 사용할 도커 이미지 |
| `ports` | 포트 연결 (내 PC:컨테이너) |
| `environment` | 환경변수 설정 |
| `volumes` | 데이터 유지할 폴더 연결 |
| `depends_on` | 실행 순서 지정 |

## 실행 — docker-compose up

`docker-compose.yml` 파일이 있는 폴더에서 실행해요.

```bash
docker-compose up -d
```

`-d` 붙이면 백그라운드로 실행돼요. 안 붙이면 터미널에 로그가 쭉 출력돼요.

## 상태 확인 — docker-compose ps

지금 실행 중인 컨테이너 목록이에요.

```bash
docker-compose ps
```

```
NAME         IMAGE      STATUS    PORTS
my-web       nginx      Up        0.0.0.0:8080->80/tcp
my-db        mysql:8.0  Up        3306/tcp
```

## 로그 확인 — docker-compose logs

컨테이너 로그를 볼 수 있어요.

```bash
# 전체 로그
docker-compose logs

# 특정 서비스 로그
docker-compose logs web

# 실시간으로 보기
docker-compose logs -f web
```

## 중지 및 삭제 — docker-compose down

컨테이너를 멈추고 삭제해요.

```bash
docker-compose down
```

이미지까지 같이 지우고 싶으면 `--rmi all` 붙이면 돼요.

```bash
docker-compose down --rmi all
```

## 정리

```bash
# 실행
docker-compose up -d

# 상태 확인
docker-compose ps

# 로그 확인
docker-compose logs -f

# 종료 및 삭제
docker-compose down
```

`docker run` 명령어를 매번 치는 것보다 파일로 관리하면 팀원이랑 환경 공유할 때도 훨씬 편해요. 파일 하나 공유하면 끝이거든요.
