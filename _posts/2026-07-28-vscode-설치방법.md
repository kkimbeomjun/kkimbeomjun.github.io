코딩을 시작한다면 에디터부터 설치해야 해요. 그중에서 가장 많이 쓰는 게 **VS Code (Visual Studio Code)** 예요. 무료고, 가볍고, 확장 기능이 많아서 입문자부터 실무자까지 다 써요.

## VS Code 설치 순서

**1. 공식 사이트 접속**

[https://code.visualstudio.com](https://code.visualstudio.com) 접속 후 **Download for Windows** 클릭

**2. 설치 파일 실행**

다운로드된 `.exe` 파일 실행 → 약관 동의 → 설치 옵션에서 아래 두 개 체크 권장:
- **PATH에 추가** (터미널에서 `code` 명령어 사용 가능)
- **탐색기에서 우클릭 메뉴에 추가**

**3. 설치 완료**

설치 후 VS Code 실행하면 끝이에요.

## 한국어 설정 (선택)

처음 실행하면 영어로 되어 있어요. 한국어로 바꾸려면:

1. `Ctrl + Shift + P` 누르기
2. `Configure Display Language` 입력
3. **한국어** 선택 후 재시작

## 추천 확장 프로그램

VS Code는 확장 프로그램으로 기능을 추가해요. 왼쪽 사이드바 **Extensions** 탭에서 검색해서 설치하면 돼요.

| 확장 프로그램 | 용도 |
|---|---|
| Korean Language Pack | 한국어 메뉴 |
| C/C++ (Microsoft) | C언어 문법 강조 |
| Code Runner | 코드 바로 실행 |
