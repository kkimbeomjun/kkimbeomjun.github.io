[WSL2 활성화](/posts/윈도우-WSL2-활성화/)까지 끝냈으면 이제 도커 데스크탑(Docker Desktop)을 설치할 차례예요. 설치 자체는 단순한데 설정 한 가지만 확인하면 돼요.

## 도커 데스크탑 다운로드

[Docker 공식 사이트](https://www.docker.com/products/docker-desktop/)에서 **Windows용 설치 파일**을 받아요. 파란 버튼에서 "Download for Windows"를 클릭하면 돼요.

파일 크기가 꽤 커요. 네트워크 상태에 따라 다르지만 몇 분 걸릴 수 있어요.

## 설치

다운받은 `Docker Desktop Installer.exe` 실행하면 설치가 시작돼요.

![도커 데스크탑 설치 화면](/assets/img/도커설치.png)

설치 화면에서 아래 옵션을 확인하세요.

- **Use WSL 2 instead of Hyper-V** — 반드시 체크되어 있어야 해요. WSL2를 먼저 켜둔 이유가 여기 있어요.

체크 확인하고 OK 누르면 설치 진행돼요. 설치 완료 후 **재시작** 요청이 뜨면 재시작해요.

## 도커 데스크탑 실행

재시작 후 도커 데스크탑을 열면 대시보드 화면이 나와요.

![도커 데스크탑 대시보드](/assets/img/도커_대시보드.png)

상단에 **고래 아이콘이 초록색**이면 도커가 정상 실행 중이에요. 처음 켜면 엔진 시작하는 데 30초~1분 정도 걸려요.

## 설치 확인

PowerShell에서 버전 확인해볼게요.

```powershell
docker version
```

![docker version 실행 결과](/assets/img/dockerversion.png)

클라이언트랑 서버 둘 다 뜨면 정상이에요. 서버 쪽이 안 뜨면 도커 데스크탑이 아직 실행 중이 아닌 거예요.

## 테스트 실행

정상 동작하는지 확인하는 가장 빠른 방법이에요.

```powershell
docker run hello-world
```

```
Hello from Docker!
This message shows that your installation appears to be working correctly.
...
```

이 메시지가 뜨면 설치 완료예요. 도커가 hello-world 이미지를 Docker Hub에서 받아다가 컨테이너로 실행한 거예요.

---

도커 데스크탑 설치까지 끝났으면 실제로 쓸 준비가 된 거예요. 다음 포스트에서는 도커 기본 명령어를 다뤄볼게요.
