[도커 데스크탑 설치](/posts/도커-데스크탑-설치/)까지 끝났으면 이제 실제로 써볼 차례예요. 처음엔 명령어가 낯설 수 있는데, 몇 가지만 알면 대부분 상황을 커버할 수 있어요.

## 이미지 받기 — docker pull

Docker Hub에서 이미지를 내려받는 명령어예요.

```bash
docker pull nginx
```

`nginx` 자리에 원하는 이미지 이름 넣으면 돼요. 버전 지정하고 싶으면 `nginx:1.25` 이런 식으로 태그 붙이면 돼요. 태그 안 붙이면 자동으로 `latest`로 받아요.

## 이미지 목록 확인 — docker images

내 컴퓨터에 받아놓은 이미지 목록이에요.

```bash
docker images
```

```
REPOSITORY   TAG       IMAGE ID       CREATED        SIZE
nginx        latest    a72860cb95fd   2 weeks ago    192MB
```

이미지 이름, 태그, ID, 크기가 나와요.

## 컨테이너 실행 — docker run

이미지를 실행해서 컨테이너로 만드는 명령어예요.

```bash
docker run -d -p 8080:80 --name my-nginx nginx
```

옵션이 좀 있는데 하나씩 보면 돼요.

| 옵션 | 설명 |
|------|------|
| `-d` | 백그라운드로 실행 (터미널 안 막힘) |
| `-p 8080:80` | 내 컴퓨터 8080포트를 컨테이너 80포트에 연결 |
| `--name my-nginx` | 컨테이너 이름 지정 |

이렇게 실행하면 브라우저에서 `http://localhost:8080` 열면 nginx 화면이 나와요.

## 실행 중인 컨테이너 확인 — docker ps

지금 돌고 있는 컨테이너 목록이에요.

```bash
docker ps
```

```
CONTAINER ID   IMAGE   COMMAND   CREATED         STATUS         PORTS                  NAMES
a1b2c3d4e5f6   nginx   ...       2 minutes ago   Up 2 minutes   0.0.0.0:8080->80/tcp   my-nginx
```

멈춰있는 컨테이너까지 보고 싶으면 `-a` 붙이면 돼요.

```bash
docker ps -a
```

## 컨테이너 중지 — docker stop

실행 중인 컨테이너를 멈춰요.

```bash
docker stop my-nginx
```

컨테이너 이름 대신 ID 앞 몇 자리 써도 돼요. `docker stop a1b2` 이런 식으로요.

## 컨테이너 삭제 — docker rm

멈춘 컨테이너를 삭제해요. 실행 중인 상태에서는 삭제 안 돼요 (먼저 stop 해야 함).

```bash
docker rm my-nginx
```

## 이미지 삭제 — docker rmi

받아놓은 이미지를 삭제해요. 이미지로 만든 컨테이너가 남아있으면 삭제 안 돼요.

```bash
docker rmi nginx
```

## 한 번에 정리

```bash
# 이미지 받기
docker pull nginx

# 컨테이너 실행
docker run -d -p 8080:80 --name my-nginx nginx

# 확인
docker ps

# 중지
docker stop my-nginx

# 삭제
docker rm my-nginx
```

이 흐름만 알면 웬만한 건 다 돼요.
